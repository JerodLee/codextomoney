# NovelForge — 소설 · 게임북 집필 플랫폼

GUI 기반의 장편 소설 / 게임북 집필 도구입니다. 설치나 서버 없이 브라우저에서 바로 실행됩니다.
본문 생성과 평점 산출에는 Claude API를 사용합니다.

## 실행 방법

1. `novelforge` 폴더의 `index.html`을 브라우저(크롬 권장)로 엽니다.
   - 더블클릭으로 열어도 되고, 원한다면 로컬 서버로 열어도 됩니다:
     ```bash
     cd novelforge
     python -m http.server 8000
     # 브라우저에서 http://localhost:8000 접속
     ```
2. 우측 상단 ⚙️ **설정**에서 Anthropic API 키를 입력합니다.
   - 키는 이 브라우저(localStorage)에만 저장됩니다. 개인 PC에서 본인 키로만 사용하세요.
   - 모델 기본값: `claude-opus-4-8`.

## 작업 흐름 (탭 순서)

1. **작품 설정** — 제목, 총 회차 수, 회차당 권장 분량(기본 5,500자), 장르, 로그라인, 전체 줄거리.
2. **사건·인물 캔버스** — 마우스 드래그로 카드를 배치합니다.
   - 먼저 주요 **사건**을 놓고, 그 사건과 연관된 **인물**을 추가해 연결(연결선 자동 표시)합니다.
3. **주제·갈등** — 주인공의 근본적 문제, 세계관의 화두, 인물 간 목적의 갈등을 정리합니다.
4. **부·장 구성** — 각 부/장별 스토리 진행을 요약하고, 그 아래에 회차를 배분합니다.
5. **회차 집필** — 회차마다 4개의 입력창으로 작업합니다.
   - ① 회차 요약 — 이번 화의 뼈대
   - ② 회차 상세 정리 — 장면·대사·전개 설계도
   - ③ 보조 메모 — 등장인물·복선·아이디어
   - **✨ 생성하기** — 위 설계 + 작품 컨텍스트로 1회분 본문을 스트리밍 생성
   - ④ 회차분 본문 — 생성 결과를 확인·수정 후 저장
   - **권장 분량 대비 현재 분량**이 실시간 표시됩니다 (예: `5,500자 / 현재 4,820자`).
   - **✅ 최종 저장 및 평가** — 진행 속도·박진감·중요도·개그 요소 등을 가상 평점으로 매기고,
     총평과 개선점을 피드백 창에 표시합니다. 개인 메모도 남길 수 있습니다.

## 데이터 · 백업

- 모든 데이터는 브라우저 localStorage에 저장됩니다.
- 상단의 **⬇ 백업 / ⬆ 복원**으로 작품을 JSON 파일로 내보내고 불러올 수 있습니다.
- 여러 작품을 만들고 상단 드롭다운으로 전환할 수 있습니다.

## 참고

- 브라우저에서 직접 Anthropic API를 호출합니다(`anthropic-dangerous-direct-browser-access`).
  개인용 로컬 도구 용도이며, 공개된 웹사이트에 배포해 키를 노출하지 마세요.
- 향후 확장 아이디어: 게임북 분기(선택지) 편집, 캐릭터 관계도 자동 생성, 문체 일관성 검사,
  전체 원고 합본 내보내기(EPUB/DOCX) 등.
