# KBO 시뮬레이터 — 한국 프로야구 전력분석 & 경기예측 보드

브라우저에서 바로 열리는 단일 HTML 파일입니다. 외부 라이브러리·네트워크 없이 동작합니다.

```
kbo-simulator/index.html   # 파일을 브라우저로 열기만 하면 됨
```

## 무엇을 할 수 있나

1. **순위·전력** — 10개 구단 정규시즌 순위표(승·패·무, 승률, 게임차, 득실, 최근 10경기, 연속기록). 1~5위 가을야구 진출권 표시.
2. **구단·선수** — 구단 카드에 **상승세/하락세(모멘텀)** 표시. 카드를 누르면:
   - 팀 타율/장타율/ERA/득실점 + 주요 타자·투수 라인업
   - **부문별 리그 순위**(득점력·타율·출루율·장타력·방어율·WHIP)로 **취약부문/강점** 자동 진단
   - **향후 5경기 일정**(경기별 예상 승률 포함)
   - **취약 선수층**과 **한 줄 개선점**
   - 선수 행에 **마우스오버**하면 → 연봉 등급(1~5), 연봉 대비 가성비(S~D), 부상 이력, 팀플레잉 점수, 문제점/개선점 진단 툴팁
3. **상대전적** — 10×10 상호 전적 매트릭스(우세=초록, 열세=빨강, 격차가 클수록 진하게). 구단명 열 고정.
4. **경기 시뮬레이션** — 홈/원정 구단과 전략을 고른 뒤 수천 경기를 몬테카를로로 돌려
   승률·평균 예상 스코어·최다 예상 스코어·연장/완봉 확률·득점 분포·핵심 변수를 산출.
   결과가 나오면 우세팀 마스코트가 튀어오르고 **색종이 세리머니**가 터집니다.

## 재미 요소

- **구단별 픽셀(도트) 마스코트** — 10개 구단 고유 12×12 도트 아이콘(호랑이·사자·쌍둥이공·곰·마법사모자·
  로켓·거인주먹·독수리·공룡·히어로마스크)을 캔버스로 생성해 순위표·구단 카드·상대전적·스코어보드에 사용.
- **응원 마스코트** — 헤더의 픽셀 야구공 캐릭터를 누르면 응원 한마디를 말풍선으로 외칩니다.
- **홈런 세리머니** — 시뮬레이션 결과에 우세팀 마스코트 팝 애니메이션 + 팀 컬러 색종이.
- 모든 애니메이션은 `prefers-reduced-motion` 설정을 존중합니다.

## 시뮬레이션 방식

- 팀 **득점력(RS/G)** 과 상대 **실점력(RA/G)** 을 리그 평균 대비로 결합해 경기별 기대득점을 계산합니다.
  - `기대득점(홈) = 홈 RS/G × 원정 RA/G / 리그평균 × 전략보정 × 홈이점`
- 점수는 **감마–포아송(음이항) 분포**로 샘플링해 야구 특유의 득점 편차를 반영합니다.
- **홈 이점**(약 +4%)과 **전략별 보정**(공격력·실점억제·변동성)을 적용하고, 9회 동점 시 연장 가중 확률로 승부를 가립니다.
- **피타고리안 승률**을 교차검증 지표로 함께 표시합니다.

### 전략 옵션
| 전략 | 효과 |
|---|---|
| 균형 | 표준 운용 |
| 강공·장타 | 득점 기대 ↑, 편차 ↑ (폭발 or 침묵) |
| 정교한 타격 | 안정적 득점, 기복 ↓ |
| 불펜 총력전 | 실점 억제, 접전 유리 |
| 에이스 선발 | 상대 타선 봉쇄, 실점 크게 ↓ |
| 스몰볼·기동력 | 저득점 접전 유도 |

## 데이터 수정

순위·기록·선수 스탯은 실제 KBO 구단·선수를 바탕으로 한 **대표성 있는 예시 데이터(2025 시즌 기준)** 이며
실시간 공식 기록이 아닙니다. `index.html` 안의 `DATA` 배열과 `ROSTERS` 객체를 수정하면
최신 수치로 갱신되고 순위·전적·시뮬레이션에 즉시 반영됩니다.
